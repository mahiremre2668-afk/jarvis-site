Jarvis — Privacy Policy

Last updated: 16 October 2026

Who uses Jarvis

Jarvis is a private personal assistant used only by its owner (contact: mahiremre2668@gmail.com). It runs on the owner's own computer. It has no other users and is not offered to the public.

What Google data it accesses

  • Gmail: reads the owner's own messages to summarise them and flag important ones; drafts are created only when the owner asks.
  • Google Calendar: reads and creates events in the owner's own calendars for reminders.
  • Google Drive: reads files the owner asks about.

How the data is used and stored

  • Data is processed on the owner's computer and stored there. It is not sold, shared, or transferred to third parties.
  • Short excerpts may be sent to an AI model provider (Google Gemini) only to produce answers for the owner.
  • Data is not used for advertising or to train general AI models.
  • Access tokens are stored locally with restricted file permissions and can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
